# QingIcon

<p align="center">
  <a href="./README.md">English</a> | <a href="./README.zh-CN.md">简体中文</a>
</p>

QingIcon 是一套**规范化、中性风格**的 UI 图标库，免费且开源（Apache 2.0），面向 AI、云服务与互联网产品。图标尺寸统一、视觉重量均衡，出自同一套设计规范，混排不突兀。

- **3900+ 枚图标**，覆盖 **34 个分类**；
- **Line（线性）/ Fill（填充，加班绘制中）** 双风格；
- **137,235 条中英双语关键词**，搜索召回率高，"想到什么基本就能搜到"；
- 官网在线浏览、搜索、复制与下载；另有 React / Vue 组件、MCP Server 与 Figma 插件。
- 官网：https://qingicon.com



## 基础能力

### 中性、统一的视觉语言
尺寸统一、视觉重量均衡，图标也能遵守能量守恒定律。

### 草图风格（Sketch）
一键把任意图标切换成手绘草图质感（速写的不规则与温度感），从工程感变成"人在思考"的氛围。适合概念稿、线框、头脑风暴、教学与提案。同一套图标在"中性风"与"草图风"之间秒切、无损替换。

> 草图风格为**官网与 Figma 插件**的设计侧能力，不进入 npm 组件包与 MCP，开发者若想将该能力应用到工程文件中，可自行引入 Rough.js。

### 中英文搜索
13.7 万条中英双语关键词，同时我们做了大量工程打磨：

- **中文分词 + 模糊容错**：基于浏览器内置 `Intl.Segmenter` 做中文分词，无空格中文自动切词、按多词 AND 命中；残片也能归位——输入 `早蛋` 这种只记得一半的组合，照样召回含 `早餐` + `鸡蛋` 的图标。
- **英文侧**：归一化（`userpen`→`user-pen`）、词序无关（`pen user`→`user-pen`）、模糊兜底（`pecil`→`pencil`）。

### 抽象图标（永远有图标可用的兜底素材库）
库内 **Abstract 类图标**，语义宽泛、百搭。当某个功能一时找不到贴切的具象图标时，抽象图标就是万能替补——以"容器 / 标记 / 装饰 / 占位"身份塞进任何界面，保证永远不空屏。这也是把抽象类做得又大又全且不断扩充的原因：它是整套库的兜底方案。

### 云计算 / AI 等场景化
按产品域成体系补齐，专门服务 AI、云服务与互联网产品：

- **AI 图标**：覆盖模型、推理、训练、Agent、神经网络、向量、提示词、对话等 AI 产品全链路。
- **云计算 / 网络图标**：服务器、数据库、容器、网络、存储、CDN、监控等云原生 / 云服务基础元件一应俱全，画云架构图、云控制台、SaaS 仪表盘都够用。
- 这些家族与库内其余 UI 图标共用同一套中性网格，混排绝不打架——**一个 QingIcon 就能撑起「AI + 云」类产品的整套界面**，不必混用三四个风格各异的图标源。

### Optical 光学修正
缩放图标时自动保持描边视觉粗细一致，避免小尺寸下线条变粗、大尺寸下变细的失真。

### Padlock 跨工具占位
导出 SVG 时写入一层**隐形方形边界层**（`fill=none stroke=none`），让 Sketch / Figma 等外部工具更好地保留图标画布尺寸，跨工具一致。

### 多格式导出
在线实时调节描边、尺寸与颜色。一键复制 **SVG / React / Vue / DataURL**，并支持下载 **SVG / PNG / WebP**，后续将支持更多导出能力。



## 为什么做这个项目

市面上很多图标库让我长期不满意：图标尺寸不统一、视觉重量失衡，又缺少适配多样场景的通用抽象图标。在 AI 盛行的时代，我决定沉下心来打磨一些设计基础服务，沉淀一份属于设计师的得意之作——于是有了这个项目。



## 周边生态

| 生态 | 说明 | 链接 |
|---|---|---|
| **官网** | 在线浏览 / 搜索 / 复制 / 下载 | https://qingicon.com |
| **React 组件** `qingicon-react` | 每图标一个 `Qi{Name}` 组件，Tree-shaking、TypeScript、Optical | [npm](https://www.npmjs.com/package/qingicon-react) |
| **Vue 组件** `qingicon-vue` | 同上，Vue 3 组件 | [npm](https://www.npmjs.com/package/qingicon-vue) |
| **MCP Server** `qingicon-mcp` | 在 AI 编码工具（Cursor、Claude Code、Codex、VS Code Copilot 等）中通过自然语言直接搜索或查找匹配的图标，生成可粘贴的 React / Vue 组件代码，或纯 HTML 内联 SVG | [npm](https://www.npmjs.com/package/qingicon-mcp) |
| **Figma 插件** | 把图标库搬进 Figma | https://www.figma.com/community/plugin/1686396239772536401 |
